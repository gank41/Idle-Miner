# Idle Miner 1.6.1 (build 9)

Mining Stats now opens larger and remains resizable on Mac and Linux. The Mac remembers your chosen Stats size when reopened during the same app session. Smaller displays retain scrolling so controls remain reachable.

This update changes Stats sizing. It carries forward the wallet, multiple-currency, shared CPU limit, visibility, session-clock, and safety behavior from version 1.6.

## Downloads and installation

Download from [GitHub Releases](https://github.com/gank41/Idle-Miner/releases):

- **Mac:** `Idle-Miner-1.6.1-macOS.dmg` — Apple Silicon, macOS 14 or later. Drag Idle Miner to Applications. The app is locally ad-hoc signed and has not been notarized by Apple. Read the [installation guide](https://github.com/gank41/Idle-Miner/blob/main/HOWTO.md#install-on-a-mac) and [Apple's opening instructions](https://support.apple.com/en-us/102445) before approving an exception; only do so for software you trust.
- **Linux:** `Idle-Miner-1.6.1-Linux.tar.gz` — source installer for supported 64-bit ARM/x86 Fedora, Fedora Asahi, or recent Ubuntu/Debian-family desktops with Qt 6/PySide6 and KDE Frameworks 6 dependencies available. Extract it and run `bash install.sh` as your normal user. `sudo` is requested only for missing system packages.

**Updating:** stop and quit **all** currency instances before replacing or reinstalling. Existing wallets and settings are preserved. The app normally opens stopped; reopen and start additional currencies when ready.

See [Install and use](https://github.com/gank41/Idle-Miner/blob/main/HOWTO.md), [Privacy](https://github.com/gank41/Idle-Miner/blob/main/PRIVACY.md), and [Third-party notices](https://github.com/gank41/Idle-Miner/blob/main/THIRD-PARTY-NOTICES.md).

## Verification and limitations

| Area | Evidence available for this release |
| --- | --- |
| Mac Stats sizing | Native resize/reopen and content-fit checks passed. The recorded populated document was 820 points high within an 860-point viewport. |
| Mac update and packaging | App version/build and local signature were verified; installer contents were inspected and saved settings were preserved. Running profiles were restored and reached the requested one-thread engine state. |
| Existing mining behavior | Prior checks covered offline engine work, wallet/profile switching, shared thread limits, visibility, session clocks, and supervisor cleanup. These are different from proving provider rewards or a wallet deposit. |
| Linux 1.6.1 | Seven core tests passed and the source installer was packaged. The native Linux GUI was **not retested for this update**. |
| Earlier Linux desktop evidence | Version 1.6 was built and exercised in an Ubuntu 26.04.1 ARM64 GNOME Wayland guest using isolated dependencies. The ordinary package-manager dependency-install step remained unverified while an existing OS update held package locks. Earlier Fedora desktop checks do not establish a new Fedora build-9 pass. |
| Fedora Asahi / native Asahi | Local builds request 16 KB-compatible ELF alignment. Native Asahi hardware/kernel operation remains **untested**. |
| Payouts and sustained use | No confirmed wallet deposit, guaranteed earnings, or complete physical sleep/wake/battery and long-duration high-thread thermal validation is claimed. |

Pool balances can include other devices and past sessions. Current provider rules and payout settings determine whether a payout occurs; a wallet or exchange deposit must be confirmed separately. Fees and thresholds can change, and mining costs can exceed earnings.
