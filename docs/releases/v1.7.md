# Idle Miner 1.7 (build 10)

Ethereum joins Bitcoin, Litecoin and Dogecoin as a payout currency. Save a native ETH Receive address in Settings, then switch currency or open a separate profile. ETH uses the same shared CPU allowance, Stats, and safety checks as the other currencies.

Ethereum uses [proof of stake](https://ethereum.org/developers/docs/consensus-mechanisms/pow/mining/): this app does not directly mine Ethereum. Idle Miner runs CPU RandomX work and [unMineable converts credited rewards into ETH](https://unmineable.com/coins/ETH). ETH addresses use `0x` plus 40 hexadecimal characters; all-lowercase or all-uppercase hex is accepted, while mixed case must pass EIP-55 checksum validation. Address format validation cannot identify the network or prove a destination can receive funds. The provider defaults to Ethereum; confirm its payout network matches the wallet or exchange's ETH Receive network before mining. Provider network settings, thresholds, and fees are managed outside Idle Miner and can change.

## Optional mining at login

Settings adds **Start at Login and Start Mining configured currencies** directly beneath Start at Login. This is **off by default**. Start at Login alone opens the default instance stopped. Enable both to start automatic mining for every valid saved BTC, LTC, DOGE, and ETH address on an actual login launch. Currencies without a saved address are skipped. Invalid or unreadable settings require attention before automatic startup. No wallet is created or copied to another currency.

Manual openings remain stopped. Turning off Start at Login clears and disables the mining checkbox. All profiles share the configured CPU limit and safety checks. Each active engine needs its own roughly 2 GB RandomX dataset; using several currencies increases memory, electricity and heat use after login.

## Downloads and installation

- [Idle-Miner-1.7-macOS.dmg](https://github.com/gank41/Idle-Miner/releases/download/v1.7/Idle-Miner-1.7-macOS.dmg) — Apple Silicon, macOS 14 or later. Drag Idle Miner to Applications. Locally ad-hoc signed and **not Apple-notarized**. Read the [installation guide](https://github.com/gank41/Idle-Miner/blob/main/HOWTO.md#install-on-a-mac) and [Apple's opening instructions](https://support.apple.com/en-us/102445).
- [Idle-Miner-1.7-Linux.tar.gz](https://github.com/gank41/Idle-Miner/releases/download/v1.7/Idle-Miner-1.7-Linux.tar.gz) — source installer for supported 64-bit ARM/x86 Fedora, Fedora Asahi, or recent Ubuntu/Debian-family desktops with Qt 6/PySide6 and KDE Frameworks 6 dependencies available. Extract and run `bash install.sh` as your normal user; sudo is used only for missing system packages.
- [Idle-Miner-1.7-source.tar.gz](https://github.com/gank41/Idle-Miner/releases/download/v1.7/Idle-Miner-1.7-source.tar.gz) — corresponding app and engine source. Verify downloads against the checksums supplied with the release.

**Updating:** stop and quit all currency instances before replacing or reinstalling. Existing wallets and settings are preserved; ETH remains blank until you supply an address and login mining remains off until explicitly enabled.

See the [complete guide](https://github.com/gank41/Idle-Miner/blob/main/HOWTO.md), [Privacy](https://github.com/gank41/Idle-Miner/blob/main/PRIVACY.md), and [Third-party notices](https://github.com/gank41/Idle-Miner/blob/main/THIRD-PARTY-NOTICES.md).

## Verification and limitations

These checks were run for build 10. A simulated login decision does not prove an actual operating-system logout/login cycle.

| Area | Evidence available for this release |
| --- | --- |
| Mac core and ETH validation | 59 policy/wallet/settings checks plus ETH ERC-55 examples, malformed/zero address rejection, Keccak, payout routing, migration and stale-preference checks passed. |
| Mac Settings, login consent and launch behavior | Native Settings checks passed for four wallets and the parent/child login controls. Isolated native controller checks verified four-currency launch arguments and manual-launch behavior; Apple login-event recognition was tested with a constructed event. A real OS logout/login and end-to-end login delivery were not performed. |
| Mac engine and packaging | Native build and installed version/signature checks passed. Offline engine 1→2→1 thread reloads reused the dataset; actual ETH/default controller subprocesses respected the shared cap and cleaned up after quit/crash. Settings were byte-checked during installation. 53 price, earnings, freshness and health checks passed, including ETH response-address normalization. Live ETH pool acceptance and wallet deposits were not tested. |
| Linux core and ETH/login behavior | 40 tests passed on Fedora 44 ARM64 with Python 3.14.8 and PySide6 6.11.2, including ETH, opt-in startup decisions, wallet merging, reporting, installer migration and supervisor lifecycle. |
| Linux desktop and installer | Native Fedora Qt controls and startup behavior passed with an offscreen Qt platform. The source installer includes the new startup module. A full fresh package-manager dependency installation/engine build, Ubuntu desktop check, and real OS logout/login were not repeated for 1.7. |
| Fedora Asahi / native Asahi | Native hardware/kernel operation remains **untested**. |
| Payouts and sustained use | No confirmed wallet deposit, guaranteed earnings, or complete physical sleep/wake/battery and long-duration thermal validation is claimed. |

Accepted shares and pool balances are not wallet deposits. Payouts depend on current provider rules and settings; confirm a deposit in the receiving wallet separately. Mining costs can exceed earnings.
