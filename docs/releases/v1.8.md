# Idle Miner 1.8 (build 11)

Idle Miner now uses [idleminer.app](https://idleminer.app/) for its website, installers, corresponding source downloads, and manual update information. The [GitHub repository](https://github.com/gank41/Idle-Miner) remains available for public source and issues.

## What changed

- Currency instances share one menu bar icon on Mac and one tray icon on Linux, with controls for each running currency.
- **Check for Updates…** checks for a newer version when you choose it. You can read the release notes and download the matching installer. No wallet addresses, balances, mining logs, or saved settings are included in the update request.
- Updates remain manual: stop mining, quit every currency instance, and install the downloaded package. Existing wallets and settings remain in your account.

The existing BTC, LTC, DOGE and ETH payout currencies, shared CPU allowance, idle control, and optional mining at login remain available. Idle Miner runs RandomX work through unMineable; the provider handles payout conversion. Accepted shares are not wallet deposits and earnings are not guaranteed.

## Verification and limitations

The current release was checked as follows:

- **Mac:** native release build and strict ad-hoc signature verification; 59 core checks, 53 statistics/health checks, 70 update-check assertions, and the existing engine, settings, login-consent, Ethereum and multi-instance regressions passed. Actual offline engines retained their dataset across thread reloads and respected the shared CPU allowance.
- **Shared Mac menu:** four separate native controller processes showed one visible ₿ icon, four colored currency submenus, correct remote Stats targeting, switched-profile routing and graceful owner handover. This isolated test used labeled synthetic statuses and did not mine or contact a pool.
- **Linux:** all 55 tests passed on Fedora 44 ARM64, with no skips, including shared-tray ownership/handover, rapid Start/Stop ordering, currency-bound targeting, updates, supervisor cleanup and wallet/settings preservation. A native Wayland window check passed. That GNOME environment has no system tray, so tray ownership was tested with Qt offscreen; a visible native tray interaction was not verified.
- **Packages:** installer checksums, corresponding-source parity, private-content exclusion, Mac version/signature, drag-to-Applications layout and mounted disk icon were checked before distribution.

Update parsing and failure handling were exercised using controlled responses. The live version endpoint and downloads are verified separately during deployment; no automatic installation is provided.

Native Fedora Asahi hardware operation remains **untested**. A successful build, automated check or virtual-machine run does not establish physical sleep/wake, battery, sustained thermal behavior, actual OS login delivery, or wallet deposits. The Mac package has not been notarized by Apple. Mining costs may exceed earnings.
