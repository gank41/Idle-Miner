# Idle Miner 1.9.1 (build 13)

## Resume mining after updates

A successful built-in update now restores the currencies that were enabled before it started. Automatic mining temporarily paused for activity, battery, heat or memory stays enabled and continues when the normal rules permit it. Manually stopped currencies stay stopped. Wallet validation, shared CPU limits and safety checks remain in force. Boost timers and offline benchmarks are not restored.

Actual sign-ins still follow **Start at Login** and **Start at Login and Start Mining configured currencies**. Ordinary manual openings remain stopped. A one-use private update handoff records only the previous currency states and is checked against the installation location, version and expiry. It is cleared on cancellation or failure and is not sent to the website.

**Transition from 1.9:** its updater did not capture resume state, so this first update may still reopen stopped. Subsequent updates initiated by 1.9.1 can restore state automatically. Version 1.8 and earlier still need a manual installation to gain built-in installation.
