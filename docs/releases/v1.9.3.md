# Idle Miner 1.9.3 (build 15)

## Optional update notifications

In Settings, enable **Automatically check for updates** and choose **Daily** or **Weekly**. It is off by default. Checks run while Idle Miner is open and notify when a new signed release is available. macOS may ask permission for notifications; the menu also shows available updates. Multiple currency instances share a schedule and avoid duplicate alerts. Checking does not pause mining or download an installer.

The Mac update window now uses the Idle Miner icon, a native heading, bordered notes and a preferences footer, following light/dark appearance. When you are current, notes stay collapsed. Choose **Download and Install Now** when you want to update. Existing wallet, resume and login behavior remains in place.
