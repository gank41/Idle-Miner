# Idle Miner 1.9.4 (build 16)

- Choose **Start All Mining** from the main menu to start every currency with a valid saved receive address. Idle Miner opens missing currency instances as needed and applies your shared CPU limit, idle settings and safety rules.
- Mac and Linux offer **Stop All Mining** in the main menu. On Linux, both commands are also available from the tray. Stop All cancels mining starts that are still opening.
- Menu status refreshes reuse icons while their colors stay the same. On Linux, background instances also skip reading other tray snapshots when they are presenting no tray icon.
