# Idle Miner 1.9.5 (build 17)

The Linux installer now builds the mining engine with both OpenSSL 3 and 4. This fixes a Fedora update failure near the end of compilation in `TlsGen.cpp`. Both the manual installer and the built-in updater use the fix. The Linux update window shows a short error message with expandable build details if a future build fails.

If Idle Miner opens, choose **Check for Updates** and then **Download and Install Now**. If it cannot open, quit any remaining Idle Miner currency instances, extract the Linux download and run `bash install.sh` in the extracted folder as your normal desktop user. After installation, open Idle Miner from the application menu. Saved wallets and preferences live in your user account.

The macOS About window now reports an unknown version if bundle metadata is missing. Mac users can install build 17 through the built-in updater.
