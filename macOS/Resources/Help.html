Idle Miner 1.9.2

Build 14 · By Jeffry Zander

Idle Miner uses spare CPU time for RandomX mining with XMRig. unMineable handles the pool and conversion into Bitcoin, Litecoin, Dogecoin, or Ethereum payouts. Your selected coin is the payout currency; this is not direct Bitcoin ASIC mining. Earnings vary and may be lower than electricity costs.

First setup

  1. Open Settings and paste public Receive addresses into the matching BTC, LTC, DOGE, or ETH fields. Use the coin’s native network. Leave unused coins blank. Never enter wallet passwords, private keys, or recovery phrases.
  2. Choose the currency and shared CPU limit. Save Settings; saving stops this instance’s mining.
  3. Select Start Mining when ready. Manual openings and Start at Login alone open stopped. Login mining requires the separate opt-in described below.

Ethereum payouts

Ethereum uses proof of stake and cannot be mined directly. Idle Miner mines CPU RandomX work; unMineable converts the credited rewards into ETH. Use a native ETH Receive address: 0x followed by 40 hexadecimal characters. Lowercase or uppercase hex is accepted; mixed-case addresses must pass EIP-55 checksum validation.

The provider defaults to Ethereum for ETH payouts. Before mining, use Pool Payouts to confirm that the provider payout network matches the ETH Receive network in your wallet or exchange. An address alone cannot identify its network. Provider network settings are managed outside Idle Miner. Check current fees, thresholds and deposit requirements there.

Daily controls

Automatic mode uses one thread while active, increasing after five minutes idle. Settings can instead pause completely while active. Boost allows more CPU for 15/30 minutes or 1/6/12/24 hours, then returns to automatic mode. End Boost returns early. Stop ends the session.

Battery, heat, sleep, memory pressure, and sustained CPU load can pause or reduce mining. Ordinary thread changes update the running engine and reuse its dataset; full stops and safety pauses release it. Idle Miner does not change sleep settings or keep the computer awake. Display sleep allows mining while the system remains awake.

Multiple currencies

Settings saves all four wallets. Switch Currency stops the old engine before starting the saved target when the session was running. A missing wallet opens Settings and leaves mining stopped. Open Another Currency opens a separate stopped instance; check its wallet and start it explicitly. One engine may mine each currency.

All instances share the total configured idle/Boost thread limit. Another currency does not double that limit. Each engine needs its own roughly 2 GB RandomX dataset and extra available memory. Two CPU cores are reserved where possible.

Green means fresh confirmed work; gray means stopped, paused, or starting; red means an engine, connection, or reporting issue. A working Offline Test is labeled as earning nothing. Green does not promise a payout.

Use Pool Payouts to see the provider dashboard and current threshold, fees, and automatic payout settings. The provider sends funds when its rules and settings allow it. Idle Miner does not transfer funds or change those settings. Check your wallet separately to confirm a deposit. Failed reporting is not evidence of a zero balance.

Visibility and login

Settings offers a Dock icon, menu bar icon, or both. Currency instances share one ₿ menu bar icon. Click it, then hover over a colored currency row for its summary and controls. Mining Stats in that submenu opens the full window. Keep at least one visibility option enabled. Start at Login alone opens the default instance stopped. The checkbox directly below it, Start at Login and Start Mining configured currencies, is off by default. Enabling both starts a profile for every valid saved BTC, LTC, DOGE, and ETH address on actual login launches. It skips currencies without a saved address and never creates wallets or copies addresses between currencies. Invalid or unreadable settings require attention before automatic startup. These profiles share the configured CPU limit and safety checks; each engine needs its own roughly 2 GB dataset, with electricity and heat use after login. Manual openings remain stopped. Turning off Start at Login clears and disables the mining checkbox. Offline Test performs one-thread local work for up to 70 seconds with no pool connection and no earnings.

Privacy and updates

The Mac reads unMineable statistics using your saved public address automatically while the app is open, even when stopped. Mining sends that address as part of the pool login. Price queries go to Coinbase. XMRig retains its 1% donation and can use an unencrypted donation fallback. Read the privacy and connection details.

Choose Check for Updates… to check idleminer.app when you want. The window shows installed/latest versions. When you are up to date, optional Release Notes start collapsed; click to expand them. Available updates show their changes before installation. Choose Close or Download and Install Now. Sparkle verifies the signed feed. Choosing installation stops matching currency instances and their engines before downloading, and keeps mining stopped throughout the update. It verifies the disk image before extraction, updates this app location, and restores the previous currency states after relaunch. Close before choosing installation leaves mining unchanged; canceling after that choice leaves mining stopped. macOS may request administrator authorization when needed to replace that location. Previously enabled currencies resume within idle and safety limits; manually stopped currencies stay stopped. Start at Login still applies to actual sign-ins. Ordinary manual openings remain stopped. The older 1.9 updater may leave this first transition stopped because it did not capture a resume state. Checks have no wallet data and never run automatically in the background. Version 1.8 or earlier needs one manual install of the current release to gain built-in installation.

Quit every currency instance before reinstalling or replacing the app. User settings remain outside the app in ~/Library/Application Support/Idle Miner. Logs and engine configs can contain public addresses; redact them before sharing.
