Idle Miner 1.6.1

Build 9 · By Jeffry Zander

Idle Miner uses spare CPU time for RandomX mining with XMRig. unMineable handles the pool and conversion into Bitcoin, Litecoin, or Dogecoin payouts. Your selected coin is the payout currency; this is not direct Bitcoin ASIC mining. Earnings vary and may be lower than electricity costs.

First setup

  1. Open Settings and paste public Receive addresses into the matching BTC, LTC, or DOGE fields. Use the coin’s native network. Leave unused coins blank. Never enter wallet passwords, private keys, or recovery phrases.
  2. Choose the currency and shared CPU limit. Save Settings; saving stops this instance’s mining.
  3. Select Start Mining when ready. Ordinary launches, including Start at Login, open stopped.

Daily controls

Automatic mode uses one thread while active, increasing after five minutes idle. Settings can instead pause completely while active. Boost allows more CPU for 15/30 minutes or 1/6/12/24 hours, then returns to automatic mode. End Boost returns early. Stop ends the session.

Battery, heat, sleep, memory pressure, and sustained CPU load can pause or reduce mining. Ordinary thread changes update the running engine and reuse its dataset; full stops and safety pauses release it. Idle Miner does not change sleep settings or keep the computer awake. Display sleep allows mining while the system remains awake.

Multiple currencies

Settings saves all three wallets. Switch Currency stops the old engine before starting the saved target when the session was running. A missing wallet opens Settings and leaves mining stopped. Open Another Currency opens a separate stopped instance; check its wallet and start it explicitly. One engine may mine each currency.

All instances share the total configured idle/Boost thread limit. Another currency does not double that limit. Each engine needs its own roughly 2 GB RandomX dataset and extra available memory. Two CPU cores are reserved where possible.

Stats can be resized. Reopening during the same app session retains your chosen size. Smaller screens retain scrolling.

Green means fresh confirmed work; gray means stopped, paused, or starting; red means an engine, connection, or reporting issue. A working Offline Test is labeled as earning nothing. Green does not promise a payout.

Use Pool Payouts to see the provider dashboard and current threshold, fees, and automatic payout settings. The provider sends funds when its rules and settings allow it. Idle Miner does not transfer funds or change those settings. Check your wallet separately to confirm a deposit. Failed reporting is not evidence of a zero balance.

Visibility and login

Settings offers a Dock icon, menu bar icon, or both. Keep at least one visible. Start at Login opens the default instance stopped; additional currencies must be opened and started separately. Offline Test performs one-thread local work for up to 70 seconds with no pool connection and no earnings.

Privacy and updates

The Mac reads unMineable statistics using your saved public address automatically while the app is open, even when stopped. Mining sends that address as part of the pool login. Price queries go to Coinbase. XMRig retains its 1% donation and can use an unencrypted donation fallback. Read the privacy and connection details.

Quit every currency instance before reinstalling or replacing the app. User settings remain outside the app in ~/Library/Application Support/Idle Miner. Logs and engine configs can contain public addresses; redact them before sharing.

This Mac release is locally ad-hoc signed and not Apple-notarized. Follow Apple’s documented opening instructions only if you trust the download; do not disable Gatekeeper.
